# Product Context - Eye Movement Assessment System

## Vision

A clinical-grade eye movement assessment tool that democratizes access to professional eye tracking diagnostics using standard webcam hardware.

## Problem Statement

Current eye movement assessment requires expensive specialized hardware (infrared eye trackers costing $10,000+) limiting access to major medical centers. Many eye conditions (strabismus, nystagmus, oculomotor dysfunction) could be screened earlier with accessible tools.

## Target Users

| User Type             | Primary Needs                                                |
| --------------------- | ------------------------------------------------------------ |
| **Ophthalmologists**  | Quick screening, clinical documentation, referral support    |
| **Optometrists**      | Vision therapy baseline, progress tracking                   |
| **Vision Therapists** | Exercise prescription, outcome measurement                   |
| **Researchers**       | Data collection, standardized protocols, export capabilities |

## Key Value Propositions

1. **Accessibility**: Standard webcam, no specialized hardware
2. **Clinical-Grade Accuracy**: <2° visual angle precision with validation
3. **Standardized Protocols**: Evidence-based test patterns
4. **Longitudinal Tracking**: Profile management for progress monitoring
5. **Professional Reporting**: Clinical documentation with visualizations

## Success Metrics

- Gaze estimation accuracy: <2° visual angle (validated against gold standard)
- Calibration success rate: >95% of users
- Test completion rate: >90%
- Clinical adoption: Used in professional settings

## Constraints

- Must work with standard consumer webcams (720p minimum)
- Must function in typical office lighting conditions
- Must not require specialized hardware or sensors
- Must produce reproducible results across sessions
